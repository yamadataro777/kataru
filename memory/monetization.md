# Kataru マネタイズ設計（確定版 2026-03-02）

## 確定した初期課金プラン

```
Free:     月2セッション / 要約レポートのみ / 対話なし / 保存3日
Standard: ¥1,480/月 / 月15セッション / 詳細レポート / 対話モード / 永久保存
```

## 価格の根拠
- ¥980案は原価吸収できず粗利率15%しか出なかった → 却下
- ¥1,480で粗利率63%、損益分岐の転換率は3%（100人中3人課金で黒字）
- Notion AI（¥1,350/月）と同等の価格帯。仕事用ツールとして自然

## 原価前提（1セッション）
- 基本セッション（レポートのみ）: ¥15-20
- 対話付きセッション: ¥25-45
- 無料ユーザー原価: 月2回 × ¥13 = ¥26/人/月

## Free/有料の境界設計
- 無料: 月2回、要約レポートのみ、対話モードなし、保存3日
- 有料: 月15回、詳細レポート（アクション提案・矛盾指摘・思考パターン）、対話モード、永久保存
- ペイウォール表示: 3回目セッション開始時 + レポート詳細ティーザー
- 対話モードが最大の差別化ポイント（Freeでは不可）

## 実装優先順位（最初の2週間）
### Week 1
1. セッションカウントのロジック
2. ユーザーのプラン管理（Supabaseにplan/subscription_id/current_period_end）
3. ペイウォールUI
4. Stripe Checkout連携（月額¥1,480の単一プラン + Webhook）

### Week 2
5. レポートの出し分け（Free=要約のみ / Standard=詳細）
6. 対話モードの開放条件
7. 保存期間の制御（Free=3日で自動削除）
8. Webhook堅牢化・解約処理

### 後回し
- 年額プラン、追加パック、超過課金、月次レポート（全てMonth 2以降）

## 課金の本質
- ユーザーは「考えが整理された状態」（＝レポート）に金を払う
- 録音・文字起こし・AIチャット自体には払わない
- 「話す→構造化レポート」の変換が独自価値
- 対話モードがChatGPTとの最大差別化

## 継続率の鍵
- 蓄積データへのアクセス（解約すると過去レポートが見れなくなる）
- 月次レポート（自動生成・思考傾向の分析）→ Month 2以降で実装
- 未完了アクションのリマインド
- 「迷った時のツール」→「思考を記録する習慣」への昇格が必要

## 注意事項
- 無料ユーザー増加 = 原価線形増加。転換率3%を下回ったらプロダクト品質の問題
- 最初の10人の有料ユーザーの声が全戦略を決める
- B2B/法人は初期6ヶ月は手を出さない
- ¥1,480が「高い」と言われたら価格ではなくレポートの質を直す
